# Filakaros - منصة العملات المشفرة الحديثة

منصة عملات مشفرة حديثة ومتجاوبة مبنية باستخدام Next.js 13، TypeScript، و Tailwind CSS.

## المميزات

- **تصميم حديث**: واجهة نظيفة واحترافية مع رسوم متحركة سلسة
- **متجاوب**: محسن لجميع الأجهزة وأحجام الشاشات
- **الأداء**: مبني باستخدام Next.js 13 App Router للحصول على أداء مثالي
- **TypeScript**: أمان كامل للأنواع في جميع أنحاء التطبيق
- **إمكانية الوصول**: متوافق مع WCAG مع HTML دلالي مناسب
- **محسن لمحركات البحث**: علامات وصفية، بيانات منظمة، وتحسينات الأداء

## المكدس التقني

- **الإطار**: Next.js 13 مع App Router
- **اللغة**: TypeScript
- **التصميم**: Tailwind CSS
- **مكونات واجهة المستخدم**: مكونات مخصصة مع Radix UI primitives
- **الأيقونات**: Lucide React
- **الرسوم المتحركة**: Framer Motion
- **النماذج**: React Hook Form مع التحقق من Zod
- **إدارة الحالة**: Zustand
- **البريد الإلكتروني**: Nodemailer

## البدء

### المتطلبات المسبقة

- Node.js 18+
- npm أو yarn

### التثبيت

1. استنساخ المستودع:
```bash
git clone https://github.com/fullsecure/filakaros-modern.git
cd filakaros-stable
```

2. تثبيت التبعيات:
```bash
npm install
```

3. تشغيل خادم التطوير:
```bash
npm run dev
```

4. افتح [http://localhost:3000](http://localhost:3000) في متصفحك.

## هيكل المشروع

```
src/
├── app/                    # Next.js 13 App Router
│   ├── (pages)/           # مسارات الصفحات
│   ├── api/               # مسارات API
│   ├── globals.css        # الأنماط العامة
│   └── layout.tsx         # التخطيط الجذر
├── components/            # المكونات القابلة لإعادة الاستخدام
│   ├── layout/           # مكونات التخطيط
│   ├── sections/         # أقسام الصفحة
│   └── ui/               # مكونات واجهة المستخدم
├── hooks/                # خطافات React المخصصة
├── lib/                  # وظائف المساعدة
├── styles/               # أنماط إضافية
└── types/                # تعريفات أنواع TypeScript
```

## السكريبتات المتاحة

- `npm run dev` - بدء خادم التطوير
- `npm run build` - البناء للإنتاج
- `npm run start` - بدء خادم الإنتاج
- `npm run lint` - تشغيل ESLint
